# Cardápios em PDF

A seção `#cardapio` já apresenta as duas versões por idioma. Os PDFs oficiais ainda não foram fornecidos; os botões aparecem desabilitados com a indicação “em breve”.

Quando estiverem disponíveis:

1. Salve os arquivos nesta pasta, por exemplo `cardapio-pt-br.pdf` e `menu-en.pdf`.
2. Em `index.html`, troque o botão do idioma correspondente por um link com a mesma classe `menu-language-action`, apontando para o arquivo, com `target="_blank"` e `rel="noopener noreferrer"`.
3. Atualize o texto para “Abrir o cardápio PDF” ou “Open PDF menu” e remova a indicação de indisponibilidade.

O link do WhatsApp continua disponível enquanto os PDFs são preparados. Os textos dos cartões resumem o conteúdo já presente no projeto; não constituem os PDFs definitivos.
